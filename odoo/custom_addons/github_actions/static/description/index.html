GitHub Actions Status

Show the CI status of a GitHub repository inside Odoo

This module calls the GitHub REST API and displays the workflow runs of a repository directly in Odoo: workflow name, result badge, branch, commit, duration and a direct link to the run on GitHub.

Menus

CI (GitHub Actions) > Workflow runs The list of the runs, with a Refresh button.
CI (GitHub Actions) > Configuration Repository, branch, access token and refresh options.

Configuration

owner GitHub login of the owner, e.g. NexusGit-dot.
repo Name of the repository, e.g. nexusgrid.
branch Optional, restricts the list to a single branch.
token Optional, a token with the Actions: read permission. It raises the API rate limit from 60 to 5000 requests per hour and allows watching a private repository.
limit Number of runs displayed and kept in database.
auto_refresh Refresh the status every 5 minutes with the scheduled action.

How it works

  • The runs are fetched from the GitHub API and stored in the github.actions.run table, so the list opens instantly and keeps working when the network or the API is down.
  • The scheduled action GitHub Actions: refresh the CI status updates the table every 5 minutes.
  • The button Refresh forces an immediate update.
  • A failed call never breaks the scheduled action: the last known status is kept and the error is only written in the server log.
